# paulnicholson taps

## How do I install these formulae?

`brew install paulnicholson/taps/<formula>`

Or `brew tap paulnicholson/taps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "paulnicholson/taps"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
